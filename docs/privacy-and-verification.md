# Privacy and evidence boundary

## Public material

- architecture and decision rationale
- field definitions
- synthetic records using reserved `.test` domains
- explicit limitations

## Withheld material

- scraped lead rows and workbooks
- names or contact details collected from real clinics
- source code, browser state, cookies, credentials, tokens, and paid-service IDs
- internal scoring thresholds and outreach state
- private output, resume, audit, and error files
- original repository history

## Verification statement

The case study was checked against current private operating documentation on
2026-09-02. Because no runnable implementation is published here, the honest status is
`CASE_STUDY_ONLY`. The repository makes no claim that a reader can reproduce a scrape,
and no quantity or quality metric is presented without public evidence.
